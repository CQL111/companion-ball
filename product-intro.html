它能做什么

S0 先把「陪着你」这件事做对，人格与记忆在后面的版本里长出来。

🐾
常驻桌角

全屏透明、点击穿透。拖到哪儿就待哪儿，下次启动还在原位。

💬
随时聊天

点一下它，或按 Ctrl+Alt+F。支持多轮对话，记得你们最近说过的话。

🔒
默认离线

角色、位置、聊天记录都只在本机。不配置模型也能正常使用。

🧠
可换模型

线上 DeepSeek，或本机 Ollama —— 自己选，随时切换。

怎么用

1

运行安装包，同意用户协议后，团子猫会出现在屏幕右下角。

2

按住它拖动，可以放到任何你喜欢的位置。

3

点一下它（或按 Ctrl+Alt+F）打开聊天窗口，说点什么。

4

想换模型或形象：右键托盘图标 → 设置。首次使用需要填写一个 API Key，或用本机 Ollama。

🔐 API Key 只保存在本机配置文件中，界面只显示打码片段；日志会自动打码 token。 如果你希望完全离线，可以在设置里选择本地模型。

这条路要走的路

S0 只是骨架。接下来按里程碑推进，每一步都有可验证的门槛。

S1 · 验证

角色是否可爱、是否让人想留下 —— 用真实反馈回答。

S2 · 人格

台词库、情绪状态、轻记忆：让它「像有自己的性格」。

S3 · 环境感知

在合适的时机轻轻出现，而不是不停打扰。
