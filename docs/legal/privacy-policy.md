# 隐私政策

**最后更新：2026-11-26**
**适用产品：桌面陪伴 · 团子猫（以下简称"本应用"）**
**开发者：CQL111（以下简称"我们"）**

我们尽量少收集数据。本应用的核心功能（角色、拖拽、位置记忆、聊天记录）**完全离线运行**，不联网也能使用。

**会离开本机的数据只有两类，且都是默认关闭、需你主动开启**：
- 「许愿瓶」：你写给陌生人的纸条（第一节第 4 小节）；勾选公开时还会出现在网页（第 5.1 小节）
- 「天气氛围」：你填写的城市与经纬度（第一节第 6 小节）

---

## 一、我们收集哪些数据

### 1. 仅保存在你本机、不上传的数据

| 数据 | 用途 | 存放位置 |
|---|---|---|
| 角色位置、形象偏好、动画开关 | 记住你的使用习惯 | 本机配置文件 |
| 对话记录（最近若干轮） | 支持连续追问 | 本机配置文件 |
| API Key（你填写的） | 调用 AI 服务 | 本机配置文件 |
| 日志文件 | 排查故障 | 本机日志目录 |

这些数据**不会发送到我们的服务器**（许愿瓶的纸条与勾选公开的内容除外，见第 4、5.1 小节）。删除应用或在设置中清除对应内容即可移除。

### 2. 在你使用 AI 功能时会发送给第三方的数据

只有当你**主动和角色聊天**时，才会发生网络请求：

| 发送内容 | 接收方 | 目的 |
|---|---|---|
| 你的问题与最近几轮对话上下文 | 你在设置中选择的 AI 服务（默认 DeepSeek） | 生成回答 |

我们**不会**发送：真实姓名、手机号、身份证、精确地址、设备标识、通讯录、文件内容、屏幕截图。

> AI 服务提供方会按其自身隐私政策处理这些数据（DeepSeek 隐私政策见其官网）。如果你不希望任何数据离开本机，可以：
> - 关闭 AI 功能（不配置 Key），角色仍可正常使用（只是不会聊天）
> - 改用本机 Ollama 模型（设置 → 本地模型），此时数据不出本机

### 3. 安装包内置的体验 Key

部分版本（个人体验版）内置了一个低额度 API Key，仅用于让你开箱试用 AI 功能。使用内置 Key 时，你的提问同样会发送给 AI 服务提供方。你可以在设置里换成自己的 Key，或清除内置 Key。

### 4. 在你使用「许愿瓶」时会发送到我们服务器的数据

**这是唯一会离开你设备、并由我们保存的数据。** 该功能**默认关闭**，只有你在「设置 → 许愿瓶」中主动开启后才会生效。

| 发送内容 | 用途 | 保存多久 |
|---|---|---|
| 纸条正文（≤60 字） | 让其他人能捡到并阅读 | 最多 7 天，无人捡到即删除 |
| 回信正文（≤60 字） | 送达给原投递者 | 随纸条一并删除 |
| 随机代号（如「夜里的橘子」） | 让收信人有个称呼，**每次随机生成、不复用** | 随纸条一并删除 |
| 设备令牌的哈希值 | 限流与防止滥用；**不保存令牌原文** | 直至卸载或数据清理 |
| 时段标签（清晨 / 白天 / 傍晚 / 深夜） | 让纸条漂给同一时段还醒着的人 | 随纸条一并删除 |

我们**明确不会**收集或发送：

- 你的真实姓名、手机号、邮箱、身份证号
- 你的地理位置（**不上传坐标，也不保存时区**，只上传「时段标签」）
- 你的 AI 对话、记忆、日记、笔记本内容
- 屏幕内容、窗口标题、键盘输入

**关于设备令牌**：它由本机安装时生成的随机 ID 派生，用于区分「这台设备」而不识别「你是谁」。
它在服务器上只以哈希形式保存，无法反推原文，也不与任何账号绑定。

**关于匿名代号**：每次投递或回信都会重新随机生成。同一张纸条的投递者与回信者之间，
没有任何可以关联两个身份的标识。

### 5. 许愿瓶的边界（功能设计即隐私设计）

- **不能私聊**：没有好友、没有会话列表，回信之后即结束
- **不能追问**：收信人无法回复你的回信，你也无法知道是谁回的
- **不显示数字**：没有已读、没有点赞、没有被捡次数
- **回信不保证送达**：纸条 7 天无人捡到会自动删除，不通知你

如果你不希望任何纸条离开本机，**不要开启许愿瓶**；不开启时，该功能不会产生任何网络请求。

### 5.1 把纸条公开到网页（可选，逐条选择）

许愿瓶里有一项**默认不勾选**的选项：「可以让别人在海边看到」。
只有你**每张纸条单独勾选**后，这张纸条才可能被展示在一个公开的网页上（「海边窗口」）。

| 项 | 说明 |
|---|---|
| 触发方式 | 每张纸条单独勾选，**不会记住你的选择**，默认永远不勾 |
| 展示内容 | **只有正文 + 随机代号 + 时段标签** |
| 展示时间 | 人工审核通过后，最多 30 天 |
| 审核 | 每一张都要经过人工批准；未批准的不会展示 |
| 撤回 | 你在客户端举报自己那张纸条，会立即从网页下架 |
| **不展示** | 你的名字、设备、位置、投递时间、任何次数或统计 |

**公开的纸条会被互联网上的任何人看到**（包括搜索引擎以外的人直接访问该网页）。
网页本身设置了「不被搜索引擎收录」，但这只降低、不消除被他人看到的可能。

如果你不希望纸条出现在公开网页上，**不要勾选这一项**——不勾选时，纸条仍然只在许愿瓶的私下流转中可见。

### 5.2 内测说明

当前为**小范围内测**（邀请制、不公开注册）。内测期间：

- 服务器位于中国境内，仅用于开发与功能验证，不对外提供公共服务
- 参与内测的人由我们直接邀请，不会向公众开放
- 内测数据同样适用本节的所有规则；随时可以要求删除你的全部数据

### 6. 在你开启「天气氛围」时会发送到第三方的数据

**默认关闭。** 只有你在「设置 → 天气氛围」里填写城市并主动开启后，才会产生请求。

| 发送内容 | 接收方 | 用途 |
|---|---|---|
| 你填写的城市名称 | Open-Meteo 地理编码服务 | 把城市名解析成经纬度 |
| 该城市的经纬度 | Open-Meteo 天气服务 | 获取当前天气代码 |

我们**不发送**：设备标识、安装 ID、你的其他数据。请求本身不携带任何账号或凭据——
该服务免费且不需要 API Key，因此不存在可泄露的凭据。

**城市信息只保存在本机**（配置文件中），用于下次启动时直接查询，不会上传到我方服务器。

**关闭方式**：设置 → 天气氛围 → 取消勾选。关闭后不会再产生任何天气请求。

**用途边界**：天气只影响角色的氛围表现（例如下雨时它会趴在窗边），
**不播报温度、不弹出通知、不记录历史**。角色也不会因为你所在的城市而改变其他行为。


## 二、我们不收集什么

- 不收集设备指纹、IMEI、MAC 地址、IP 之外的任何标识
- 不收集通讯录、短信、照片、文件、剪贴板
- 不做后台截屏、不做键盘记录
- 不向我们自己的服务器上报任何统计（无埋点、无遥测）；**唯一例外是许愿瓶的纸条正文**，见第一节第 4、5.1 小节
- 不出售、不出租、不共享任何数据。许愿瓶的纸条仅在你与他人的设备之间流转，不用于任何其他用途

## 三、数据存储位置与保留期限

所有本机数据位于：

- **Windows**：`%APPDATA%\companion-ball\`
- **macOS**：`~/Library/Application Support/companion-ball/`

日志文件默认保留最近 10 个（每个最大 5MB），按日期轮转。你可以随时在托盘菜单「打开日志文件夹」查看，或「清空日志」。

**许愿瓶的服务端数据**（仅在你开启该功能时存在）：纸条与回信最多保留 7 天，无人捡到或已回信后即删除；
设备令牌哈希、举报记录保留至你卸载应用或我们清理数据为止。

## 四、你的权利

| 权利 | 怎么做 |
|---|---|
| 查看本机保存的数据 | 打开上面的目录，`config.json` 为明文 JSON |
| 删除全部数据 | 卸载应用后手动删除该目录，或在设置中逐项清除 |
| 撤回 AI 授权 | 设置 → 线上模型 → 清除已存 Key |
| 不使用 AI | 不配置任何 Key 即可，其余功能正常 |
| 关闭许愿瓶 | 设置 → 许愿瓶 → 取消勾选；关闭后不再产生任何网络请求 |
| 举报违规纸条 | 读到纸条时点「举报」，该内容立即对所有用户不可见 |
| 删除对话记录 | AI 对话窗口 →「新对话」 |
| 关闭日志 | 托盘 → 日志级别 → 选择更高等级 |

## 五、儿童

本应用不面向 14 岁以下儿童。若你是未成年人，请在监护人指导下使用。

## 六、数据安全

- API Key 保存在本机配置文件中，不上传
- 日志写入时自动对 `token`、`password` 等字段打码
- 与 AI 服务之间使用 HTTPS 传输
- 应用不监听端口，不接受远程连接

请注意：本机配置文件为明文。如果多人共用一台电脑，建议不要在应用内保存他人可见的 Key。
