# 事件记忆（Occasions）：随口说一句，被记住

> P1.5「它记得那一天」的实现规格。它把**未来的事**变成猫的一等记忆。
> 上层论点见 [`PRODUCT-THESIS.md`](PRODUCT-THESIS.md) 第四节；排期见 [`ROADMAP.md`](ROADMAP.md)。
> 领域层落在 `src/core/occasions.ts`（零平台依赖，纯函数，可单测）。
> 抽取与落库的平台接线在 `src/main/`（与 `main/remember.ts` 同一层）。

## 一、要解决的一件事

用户在对话里随口说：

> 「我下周三下午要面字节。」

它应该变成：

- 一条**有日期的事实**（可见、可删、可改）
- 在**恰当的时机**被提起：接近时提一句、当天用身体动作、之后问一句结果
- 全程**不弹通知、不报数字、允许记错**

反面（不做）：弹出「已为你添加日程：11 月 27 日 15:00 面试」，点「提醒我」——
那是对日历应用的拙劣模仿，用户关心的是它准不准，而不是它在想你。

## 二、三层职责

| 层 | 谁做 | 在哪 |
|---|---|---|
| **听懂** | 关键词 + 日期词正则，命中才考虑调用便宜模型确认 | `main/remember.ts`（平台层，可访问 LLM） |
| **记住** | 规范化、去重、上限淘汰、状态机 | `core/occasions.ts`（纯函数，零平台） |
| **接住** | 生成「接近 / 当天 / 之后」三个观察，交给 `core/speech.ts` 与 `core/notebook.ts` | `core/occasions.ts` 产出，渲染层消费 |

**原则**：抽取可以「猜」（模型），但**记住与接住的规则必须可预测、可单测**。

## 三、数据模型

```ts
// src/core/occasions.ts
type OccasionKind = 'interview' | 'exam' | 'trip' | 'appointment' | 'anniversary' | 'other'

type Occasion = {
  id: string
  text: string              // 用户原话片段，用于展示与删除（不加工）
  kind: OccasionKind
  date: string              // UTC ISO，只精确到「日」：YYYY-MM-DD
  certainty: 'vague' | 'day' // 「下周三」→ vague；「11月27日」→ day
  status: 'upcoming' | 'passed' | 'dismissed'
  createdAt: string         // UTC ISO
}
```

**硬约束：**

- **只到「日」，不到「时」**。不推断到点钟——降低出错率，也避免「你怎么知道我几点」的越权感。
  用户明说「下午三点」也只记「那天」，正文里的原话保留，展示时用原话。
- **`text` 存原话**，不重写。展示用原话，日记里才可以润色。
- **上限 10 条 `upcoming`**，超出按 `date` 最近优先保留，最远的淘汰（与 `memory.ts` 的 30 条同一套纪律）。
- 状态机单向：`upcoming → passed | dismissed`，`passed/dismissed` 保留 30 天后清理。
- 全部字段可 JSON 序列化（手机端同步前提，见 ROADMAP 第六节规则 3）。

## 四、听懂：抽取规则

**零 token 路径（默认）**：正则同时命中以下两类才生成候选。

| 类 | 例子 |
|---|---|
| 事件词 | 面试 / 考试 / 笔试 / 复试 / 体检 / 复诊 / 旅行 / 出差 / 搬家 / 生日 / 纪念日 / 汇报 / 答辩 |
| 日期词 | 明天 / 后天 / 下周X / 下个月X号 / X月X日 / 周六 / 这周末 / 月底 |

命中后做**规则解析**：相对日期按本地时区折算成 `YYYY-MM-DD`；无法确定年份的（「3 月 5 日」在 3 月之后说）按「最近的未来」取。

**模型确认路径（仅当规则通过、且当次会话允许）**：

- 抽取出「事件 + 对象 + 日期」三元组，要求模型**只输出结构化结果**，不自由发挥
- **只在候选通过规则闸门后调用**，每会话最多一次；离线 / 失败直接走零 token 结果
- 模型可以**否决**候选（如「我上周面试完了」是否定语句），但不允许新增规则没扫到的事件——
  这是为了不让记忆来源不可解释

**不抽取的东西（刻意）：**

- 普通闲聊里的时间（「我今天好累」）——没有「未来的事」，不构成 occasion
- 没有日期的未来的事（「我最近要找工作」）——只有事件，没有时间锚，**允许它留在普通记忆里**
- 健康判断（「我没吃早饭」）——不建 occasion，也不建状态值

## 五、记住：写入与隐式确认

**写入时机**：抽取成功的当天，**不单独通知**，作为当天日记正文的一部分出现：

> *「今天听你说下周三要去面试。我会记得的。」*

**隐式确认**：用户看到后可以

- **划掉**（`dismissed`）——日记里这一行变为「这句话我记错了，删掉吧」，不追问
- **改日期**（未来版本，先不做）——用聊天说「面试改到周四了」→ 规则重新抽取并覆盖
- **不看**——什么都不发生

**为什么用日记确认**：弹窗确认会让它变成工具；写好之后用户自己看到，才是「它记得」。
若用户明确在对话里纠正（「是周四不是周三」），视为**最强信号**：更新该条 occasion，
并在当天日记里记录「我今天搞错了，是周四」——纠错本身成为记忆素材与互动。

## 六、接住：三个节奏

所有输出走已有的「观察 → 台词」通道（`core/speech.ts`），不新增通知通路。

| 时机 | 触发 | 形态 | 频率 |
|---|---|---|---|
| **接近** | 距 `date` ≤1 天（T-1） | 日记顶格一句 + 一次观察台词：「快到你面试了。」 | 每条 occasion 仅一次 |
| **当天** | `date` 当天 | **身体动作**：安静地守在入口 / 扒窗 / 久坐陪伴；不主动弹气泡 | 当天不限次，但受打扰预算约束 |
| **之后** | `date` 次日（T+1） | 问一句结果：「面试怎么样？」→ 用户回答写入普通记忆 | 每条 occasion 仅一次 |

**硬规则：**

- **不报时间差**：不出现「还剩 3 天」。用「快到 / 今天 / 昨天」这类相对词，放进台词库。
- **不抢焦点**：气泡 3 秒自灭、`pointer-events: none`，与现有约束一致。
- **不责备**：用户说「不想去」或干脆不提，不做任何追问；T+1 未回应即归档。
- **与打扰预算合并**：occasion 台词占用 P0 的统一预算（两次主动开口 ≥10 分钟），
  不享有特权——**越重要的事越不能说两遍**。
- **睡觉 / 打盹时**：当天动作照旧，但台词推迟到它醒着的时候（沿用 `core/petState` 状态）。

## 七、与现有模块的边界

| 模块 | 关系 |
|---|---|
| `core/memory.ts` | occasion 是**带日期的事实**，与普通记忆分开存储，不占 30 条上限；T+1 用户回答可生成普通记忆 |
| `core/notebook.ts` | 日记是 occasion 的**唯一展示口**；接受 occasion 作为素材，不让 occasion 自己拼日记 |
| `core/speech.ts` | occasion 产出一个 `Observation`，与其他观察排队，受统一打扰预算约束 |
| `core/needs.ts` | 不互相触发；「想你」与「快到你面试了」同时出现时，occasion 优先 |
| `main/remember.ts` | 抽取平台接线放这里（与普通记忆抽取同一管线），复用其失败静默降级 |

## 八、隐私与开关

- 抽取只读**用户主动输入的对话内容**，不读窗口标题、不读文件、不读日程
- occasion 只存在本地；不因 occasion 发起除既有 AI 调用外的任何出网请求
- 设置里一个开关「**让它记住还没发生的事**」，默认开；关闭即删除所有 `upcoming` 与 `passed`，
  并在日记里（若未关日记）出现一句「我以后不记这些了。」
- 隐私政策不需要为此新增条款（不上传、不新增出网），但要更新「我们记住什么」的说明

## 九、验收清单

**单测（Vitest，`core/occasions.ts`）**

- [ ] 相对日期：「下周三」→ 正确日期；跨月、跨年边界正确
- [ ] 绝对日期：「3 月 5 日」在 3 月后说 → 取最近的未来
- [ ] 否定句不抽取：「我上周面试完了」
- [ ] 无日期事件不抽取，但进入普通记忆路径（若调用方允许）
- [ ] 上限 10 条：超出时淘汰最远的、保留最近的
- [ ] 状态机：`upcoming → passed / dismissed` 单向；30 天后清理
- [ ] T-1 / 当天 / T+1 各只触发一次（假时钟）
- [ ] occasion 观察占用打扰预算，不绕过 10 分钟间隔 / 每日次数
- [ ] 关闭开关后所有 occasion 被清空

**功能测试（`tests/e2e/smoke.mjs` 增补）**

- [ ] 对话里说「我下周三要面试」→ 当天笔记本出现对应一行
- [ ] 划掉后该行消失，且不再出现 T-1 / 当天 / T+1 的台词

**真机验收**

- [ ] 说一句话 → 当天日记出现 → 不弹任何系统通知
- [ ] T-1 出现一次「快到你面试了。」，且当时用户在座
- [ ] 当天出现身体动作而不是气泡（除非用户主动点它）
- [ ] T+1 问一句结果，用户回答后写入记忆
- [ ] 记错并纠正 → 更新且日记里留下「我搞错了」
