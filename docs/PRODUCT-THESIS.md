# 产品论点：团子猫凭什么不被替代

> 这份文档只回答一个问题：**团子猫凭什么不是一个随时能被更可爱的桌宠取代的东西？**
> 读者：产品决策者、潜在投资人、以及半年后回来接手的人。
> 排期见 [`ROADMAP.md`](ROADMAP.md)；事件记忆的实现规格见 [`OCCASIONS.md`](OCCASIONS.md)。

## 一、一句话

> **我们不是做桌宠的，我们做的是会陪你的手账。**
> 桌宠是获客，笔记本是留存，年度本是变现。

这句话不是包装，是排期依据：凡是让「猫更好看」的功能，优先级低于让「用户的东西更厚」的功能。

## 二、镜鉴：Mochi 验证了方向，但没有给出答案

Nixie0/Mochi 是一个「**AI 养人类**」的自托管网页小游戏：四条状态值随时间衰减，你在聊天里说
「吃饭了」，AI 通过 MCP 更新你的状态；数值归零进医院，AI 打工赚金币赎你；五档职业、摇骰子、
业主群论坛。它是这一波「AI 陪伴」里最有代表性的形态之一。

它给我们的最大启发不是玩法，而是这一句：

> **陪伴类产品的留存引擎，不是宠物有多可爱，而是用户自己愿不愿意开口。**

用户上瘾的不是那四条数值，是**自己的话被接住**。但它接住的方式（数值 + 金币 + 惩罚）
不适合我们。逐项拆开：

| 它做了什么 | 它验证了什么 | 我们学 / 不学 | 我们的做法 |
|---|---|---|---|
| 聊天里说「吃饭了」→ 状态 +XX | 用户愿意把生活片段交给角色 | **学方向** | 说「下周三面试」→ 变成它记得的一件事，写进日记 |
| 四条数值 + 自然衰减 | 数值带来即时反馈 | **不学** | 说感受不说数据：日记里写「快到你面试了」，不写「还剩 3 天」 |
| 医院 / 上锁 / 5200 金币赎回 | 惩罚能提高短期活跃 | **不学** | 反向指标「关自启 <30%」；缺席不制造愧疚 |
| 五档打工 + 金币经济 | 游戏化延长时长 | **不学** | 不引入任何可比较的数字，许愿瓶连「被捡次数」都不显示 |
| 业主群 / 论坛 | 社区能冷启动 | **不学形态** | 只学冷启动：邀请制小圈子 + 官方种子内容 + 猫兜底 |
| 确定性 tick，LLM 只做调味 | 架构可本地优先 | **学** | 已经是我们的红线（微交互不走 LLM），继续守 |

**结论：Mochi 是镜子，不是竞品。** 它证明了「让一句话改变世界」是有效的情感钩子，
但它用游戏化的方式实现；我们用**记忆与日记**实现。它卖的是养成进度，我们卖的是私人纪念品——
两套单位经济、两套指标，不该互相抄。

## 三、诊断：我们真正缺的不是功能，是两样东西

现有产品有「三根支柱 + 一个容器」：在场感、记忆、仪式、猫的笔记本。这四样都在**回应**用户：
用户来了，它反应；用户说了，它记住。缺的是两样**主动伸出去**的东西：

1. **期待**——没有「还没发生的事」，用户就没有理由明天再来。Mochi 的数值衰减之所以让人回来，
   本质是制造了一个「未来要处理的状态」。我们不能用惩罚制造期待，但可以用**日期**。
2. **落笔**——用户目前只能「看」笔记本，不能「写」。没有用户写的部分，语料永远只是猫的独白，
   而独白积累不出关系。

由此得到**第四根支柱：期待**，以及贯穿所有阶段的北极星：**语言资产**。

## 四、第四根支柱：期待（它记得还没发生的事）

> 记忆不只是记住过去，还要**预支未来**。

用户随口一句「我下周三要面试」，她期待的不是一个闹钟，而是**它记得**。
这条支柱由三件事共同支撑，分别落在三个连续阶段：

| 机制 | 阶段 | 用户感受 |
|---|---|---|
| 缺席日志 | P1 | 「我不在的时候它也在生活，回来有东西可看」 |
| 日历记忆 | P1.5 | 「它记得我下周要面试」 |
| 页边一句 | P2 | 「我也可以留一句话给它」 |

三条规则贯穿始终（与 P0「可信的主动」一脉相承）：

- **不弹通知**：一律落在笔记本里，用户回来自己看到。弹窗会把「牵挂」变成「打扰」。
- **不报数字**：「快到你面试了」而不是「距离面试还有 3 天」。数字让记忆变成监控。
- **允许出错、允许空白**：它会记错，用户可以划掉；不是每天都有内容。**纠正本身是最强的互动**——
  Mochi 的数值是冷的，纠错是热的。

## 五、北极星：语言资产

「它记得你」不是一个功能，是一个**资产账户**。它分三层，每一层只解决一件事：

| 层 | 能力 | 现有实现 | 缺口 |
|---|---|---|---|
| **听见** | 从对话里抽取事实 | `core/memory.ts` + `main/remember.ts` | 已上线，上限 30 条 |
| **记住** | 有日期、有情绪、可删改 | 规划中 | `core/occasions.ts`（P1.5） |
| **接住** | 在恰当的时机出现，并留下痕迹 | `core/speech.ts` + `core/notebook.ts` | 缺「与记忆相关」的触发（P1/P1.5/P2） |

**为什么这是护城河**：动作、皮肤、台词库，对手一周可以抄完；用户半年攒下的日记、记忆、瓶子、
页边一句话，抄不走，也搬不走（全量可导出、可导入、端到端属于用户）。每加一个功能，先问：

> **它让这份语料更厚了吗？更可导出吗？**

**可观测的代理指标**（北极星不可直接测，用这三项代替）：

| 指标 | 含义 | 目标 |
|---|---|---|
| 周内笔记本打开 ≥2 次 | 「有没有东西可回顾」 | ≥40% |
| 周内被记忆/事件触发的日记条数 | 「语料在变厚吗」 | 观测，逐季上升 |
| 全量导出 / 年度本生成使用率 | 「用户在不在乎这份资产」 | 观测，年度 >5% |

## 六、六个机制

| # | 机制 | 一句话 | 落在哪 | 主指标 |
|---|---|---|---|---|
| **M1** | 缺席日志 | 你不在的这段时间，它也有生活；回来带一段日记 | `core/absence.ts` + 笔记本 | 缺席后本次会话打开笔记本 ≥60% |
| **M2** | 日历记忆 | 它记住还没发生的事：面试 / 考试 / 旅行 / 纪念日 | `core/occasions.ts` | 月触发 ≥3；事件删除率 <20% |
| **M3** | 不说话的身体 | 需求不只靠气泡：饿了盯入口、闷了靠边缘、想你了扒窗 | `core/motion.ts` × `core/needs.ts` | 需求态被主动触碰↑，拒绝率不升 |
| **M4** | 页边一句 | 日记每页可留一行私密回话，它可能回、也可能不回 | 笔记本 + `core/memory.ts` | 打开者周留一句 ≥30% |
| **M5** | 年度笔记本 | 一年自动成书；数字版免费，实体按需印刷 | 导出 + POD | 实体转化可观测；分享率；0 投诉 |
| **M6** | 邀请制冷启动 | 先 30–50 人小圈子 + 官方种子瓶，猫当邮差 | GTM，非代码 | 首周投递率 ≥40%；周内收到 ≥1 瓶 |

**最值得展开的三条：**

**M1 缺席日志** —— 把「缺席」做成内容，而不是流失信号。所有 AI 陪伴产品都在优化「你在的时候」，
只有桌面端能优化「你不在的时候」。离开 ≥8 小时回来，笔记本里多一段：
*「你走后下了雨，我在窗台睡了会儿，梦见一只白鸟。」* 素材 = 缺席时长 × 时段 × 天气 × 季节，
纯模板本地生成，只有 ≥3 天或生日这类特殊日子才调一次便宜模型。这引出桌面形态唯一的**结构性优势**：

> **同一场雨原则**：它和你共享同一个天气、同一个深夜、同一场初雪。聊天窗口结构上做不到。

**M2 日历记忆** —— 详见 [`OCCASIONS.md`](OCCASIONS.md)。核心是「随口一句 → 被记住 → 恰好接住」：
T-1 在日记里提一句、当天用身体动作而不是气泡、T+1 问一句结果。**不做日历、不做待办**，
不做成 Todoist 换皮；用户关心的是「它在想我」，不是「它准不准」。

**M4 页边一句** —— 让笔记本从独白变成合写。私密、≤1 行、无即时回复、不进聊天；
猫可能在下一次日记里提一句，也可能不提。它同时是最好的记忆素材，也让年度本有了
「只属于两个人的东西」。

## 七、闸门：每个阶段都是在验证一个假设

不加新功能之前，先承认一个事实：我们不缺功能，缺**证据**。所以每个节点都是闸门，不满足就停：

| 节点 | 在验证什么 | 继续的条件 | 不满足就 |
|---|---|---|---|
| S3 部署后 4 周 | 陌生人之间愿不愿意互投 | 回信率 ≥10%；有效瓶子不断供 | 停 S5/S6，回到「猫邮局没开门」+ 猫兜底 |
| P1 后 2 周 | 用户不在的时候，会不会回来看 | 缺席后本次会话打开笔记本 ≥60% | 停 P1.5/P2，先回答「用户为什么每天打开它」 |
| P1.5 后 4 周 | 未来的事能不能变成回来的理由 | 月触发 ≥3；事件删除率 <20% | 只保留起名日 / 首瓶日，砍推断事件 |
| P2 后 4 周 | 用户愿不愿意落笔 | 打开者周留一句 ≥30% | S7 降级为纯猫的日记本 |
| S7 首季 | 年度本是不是真正的变现出口 | 实体转化 ≥1%（观测） | 只做数字版 |

闸门比功能表更重要——它决定我们是在「堆功能」还是在「验证假设」。

## 八、投资逻辑

**一句话**：不是桌宠，是会陪你的手账。桌宠是获客，笔记本是留存，年度本是变现。

| 维度 | 论点 |
|---|---|
| **市场** | 不是「桌面宠物」这个小池子，是「情感手账 / 照片书 / 年度回顾」——被手账文化、按需印刷、年度回顾类内容证明过的大池子。桌宠是它在桌面上的新入口 |
| **结构性优势** | 桌面形态共享你的时间、天气、睡眠与缺席；「同一场雨」是聊天窗口永远做不到的感知 |
| **护城河** | 私人语料 + 猫的世界观。动作可抄，用户半年的日记与记忆不可复制 |
| **增长** | 只有两个自带传播的时刻：第一次收到陌生人的回信；一年后拿到年度本。其他功能为这两个时刻让路 |
| **变现** | 年度本（实体，一次性高毛利）+ 皮肤包；连接永久免费。不做抽卡、不做订阅自动续费、不把陪伴锁进付费墙 |
| **成本** | 本地优先：台词 / 日记模板 / 缺席日志零 token；LLM 只在深聊和有素材时调用；后端 Workers 免额内 |
| **为什么是现在** | 通用助手把「有用」卷到极限，情感价值反而稀缺；本地优先 + 不读窗口标题 + 不上传数据，是这一波 AI 产品唯一可承诺的隐私差异 |
| **反脆弱** | AI 与社交全部失败静默降级，角色永远可用——这是陪伴产品的常识，也是商业模式的下限 |

## 九、明确不做

| 不做 | 原因 |
|---|---|
| 状态值 / 饱食度 / 好感度可视化 | 一上屏就变养成游戏，违背「说感受不说数据」 |
| 医院 / 上锁 / 赎回 / 惩罚型留存 | 用愧疚钉人，与「关自启 <30%」「缺席不制造愧疚」直接冲突 |
| 金币 / 打工 / 等级经济 | 引入肝 / 氪 / 效率比较，与许愿瓶「一个数字都不显示」自相矛盾 |
| 待办 / 日历 / 闹钟式提醒 | 会变成 Todoist 换皮；我们做的是「记得这件事的猫」，不是提醒工具 |
| 健康判断（吃了没 / 睡得好不好） | 滑向健康监测，有合规风险；只取「事件」，不取「判断」 |
| 业主群 / 论坛 / 私聊 | 已在 ROADMAP 第四节论证：交友化是桌宠的毒药 |
| 助手功能（天气查询、写代码、日程管理） | 通用助手已赢下该市场，进入即无护城河 |
